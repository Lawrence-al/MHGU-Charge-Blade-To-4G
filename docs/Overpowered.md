# Overpowered：保留原大解派生，追加超模后摇

功能位于 `Moveset-to-4G/src/overpowered.rs`，编译进 `cb_moveset_to_4g.nro`。`[overpowered] enabled=true` 时安装一次 `main+0x002E9B7C` 派生初始化钩子；默认 false。Forge 菜单保存与游戏存档根目录的同一份 INI 同步，保存后重启应用。详见 [配置说明](Configuration.md)。

## 原派生和各风格后摇

原大解选择的链号继续保留，不再整链替换为 `0x7DC`：

| 原链 | 原资源内容 | 合并后 |
|---|---|---|
| `0x7F4` | `057a` 红盾取消，Pre=0 / Start=0 / End=28 | 原记录在前，再追加当前风格后摇 |
| `0x7F5` | `086a / 087a / 088a / 058a`，Pre=16 / Start=16 / End=33 | 四条原记录在前，再追加当前风格后摇 |
| `0x839 / 0x83A` | 所检查六份原版风格资源中为空 | 追加当前风格后摇 |

追加来源是当前玩家 `+0x24F0` 的武器派生资源，从资源 `+0x74` 的表数组读取 `0x7DC`。复用记录对象的指针，所以输入、Active、条件、动作参数和帧窗口都沿用当前风格资源。风格 0～4 各追加 8 条，炼金风格 5 追加 13 条；原命令优先于追加命令。

`0x7DC` 第 0 条 `016a` 是弹刀，追加时从序号 1 开始。正常斧竖劈使用的原 `0x7DC` 完整保留，因此斧竖劈自身的弹刀恢复原版。

旧版下列写入已移除：

| main 偏移 | 本版行为 |
|---|---|
| `011DACF0 / 011DAF74 / 011DB0B4 / 011DB0FC` | 不写入，继续使用原链 `7F5 / 7F4 / 83A / 839` |
| `002EA864` | 不安装全局弹刀查询屏蔽 |

## 运行时表副本

原 `Quest_Player_Action_InitMoveChain` 先执行，再调用合并函数。仅处理盾斧 14 且本次链确实初始化为上述四条链的情况；原返回 R0 保留。

每玩家使用一个地址稳定的 Box，包含 28 字节 `cPlCmdTbl` 表头和 48 个记录指针。`game-api/src/command.rs` 封装表头和资源读取：数量在表头 `+8`，数组指针在 `+20`，其余表头字段逐字保留。只把玩家当前表指针 `+0x24A8` 改为副本，链号 `+0x24AC` 不变。共享表、命令对象和 ARC 均不写入。

48 条上限来自玩家 `+0x24B0` 的 0x30 字节逐记录输入状态。原记录加追加记录超限时保留游戏原表并记录数量；现有六风格最大为 4+13=17 条。

同玩家重复通知不会再追加；下次原初始化写回原表后，从本次当前资源重新合并，支持换风格和资源重载。Vec 扩容只移动 Box 指针，不移动游戏正在引用的表。后续原初始化切换其它链时使用原游戏表。副本缓存跟随插件生命周期，不对游戏执行释放或引用计数操作。

没有每帧文件读取或每帧新增回调，原 main 代码洞不写入。沿用原初始化所保证有效的玩家、装备和资源对象。

## 构建与验证

从项目根目录执行：

```bash
bash "build.sh"
bash "test.sh"
node "tests/verify-overpowered.js" "D:/Work/dump-classicMH/MHGU dump"
```

测试使用六份原始 `w14_m0.arc`～`w14_m5.arc`，覆盖四条链和资源重载共 72 组，验证原记录顺序、红盾窗口、命令字段及表头保留。另验证同玩家换风格、退出大解、稳定存储、多玩家、重复通知、超限和非盾斧路径。336 组实际编译后 ARM 回调检查原函数先执行、参数／返回值、栈和被调用者保存寄存器。512 组配置组合验证新钩子只随超模开关安装。

这些是资源、代码和 ABI 离线验证；实际红盾取消和后摇派生仍需进游戏测试。原始证据和实现记录见 [本次报告](2026-10-18_逆向-超模保留红盾派生-report.md)。
