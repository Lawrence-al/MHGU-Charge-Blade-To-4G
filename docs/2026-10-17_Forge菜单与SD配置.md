# 两个盾斧插件的 Forge 设置菜单

Presentation-to-4G 与 Moveset-to-4G 均已加入 `forge_onImGuiRender`，在 Forge → Plugin UI 下分别展开 CB Presentation to 4G、CB Moveset to 4G。

配置只使用 SD 卡 `/forge/plugins/cb_presentation_to_4g.ini` 和 `/forge/plugins/cb_moveset_to_4g.ini`。手动编辑与菜单保存指向同一文件，不读取 ROMFS 配置。两个 NRO 仍安装在 `romfs/nativeNX/plugins/`。

菜单编辑草稿，Save INI 写入文件，成功后重启游戏生效；Discard edits 恢复上次保存值，Defaults 选择默认值后仍需保存。插件关闭时保留菜单入口。保存失败显示错误并保留未保存草稿。启动配置在战斗期间保持固定，不逐帧读写文件。

Presentation 可配置音效与特效开关、SRQ／PTS 修改、0x4A 音量、盾突闪电持续时间、各任务开关及触发帧、闪电持续时间。Moveset 显示原有全部配置，SAED 仍只提供 enabled 和 effect_gear。两项目共用 INI 输出、NN SD 文件读写与菜单状态代码。

构建使用原项目内的 cargo-forge 与已修复的 ARM 目标配置。当前 Forge 的 Hook 返回区为 24 字节，而旧 Rust SDK 声明 76 字节；项目内无 context 的钩子显式提供 76 字节清零区，兼容这两个已知返回布局。未修改 Forge 前置或共用 SDK。

两份 NRO 已编译并部署到现用 Ryujinx。原 Moveset INI 的全部配置值保留，旧 ROMFS 文件已移入 `work/20261017-plugin-settings/deployed-before/`；SD 文件首行路径注释已更正。其它插件及前置共 10 个文件的哈希未变。

验证通过：两个真实 UI 模块的编辑／保存／默认值／放弃／失败流程、INI 往返解析、SD 读取写入及关闭句柄、运行时配置固定；原有完整动作、HDP、SRQ／PTS 和 ARM 回归；菜单导出与全部强导入；无 TEXTREL 且全部重定位目标可写。已部署 INI 由生产解析器检查通过，NRO 不含旧 ROMFS 配置路径。

本次没有启动模拟器或实机，菜单实际显示与操作尚待游戏内测试。部署校验见 `work/20261017-plugin-settings/verification.json`；构建和完整回归日志沿用 `work/20261016-plugin-settings/`。
