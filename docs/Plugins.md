# 两份 NRO 的功能与默认修改清单

本清单对应 2026-10-06 的两 NRO 整合构建。十六进制地址为 GU v1.4.0 的 main 相对偏移；本文数值是 INI 的默认值。Moveset 的开关、范围和依赖见 [配置说明](Configuration.md)。

| 项目 | 产物 | 实现方式 |
|---|---|---|
| Presentation-to-4G | `cb_presentation_to_4g.nro` | 原动作／粒子钩子、SRQ／PTS 加载修改；任务表与执行逻辑分开 |
| Moveset-to-4G | `cb_moveset_to_4g.nro` + `cb_moveset_to_4g.ini` | 派生、SAED、Hitdata、Overpowered；按配置收集默认 31 处直接值和 2 处桥接；统一 HDP loader，按需安装 shell 钩子 |

下面的 SAED、Hitdata、Overpowered 是 Moveset 内部功能，不再生成独立 NRO。默认关闭超模，其余保持原有默认效果；Presentation 参数继续在静态任务表中。

## 1. Presentation：音效和盾牌特效

### 主动音效

主动作钩子 `0x011DABC8` 与前置动作钩子 `0x011DA204` 使用独立任务表，不能只按 actionState 区分。全部主动音效 `bank=0 / attach_index=2`；达到帧号且本次动作尚未执行该项时提交一次。

| 所属函数 | actionState | variant | 帧 | requestId |
|---|---:|---|---:|---|
| 前置 | 2 | 2、4 | 26 | `0x4A` |
| 前置 | 2 | 0～15 中除 2、4 | 50 | `0x4A` |
| 前置 | 2 | 0、7 | 30 | `0x4C` |
| 主动作 | 1 | 1、7 | 10 | `0x4A` |
| 主动作 | 1 | 1、7 | 40 | `0x56`，停止 `0x4A` 所在组 |
| 主动作 | 1 | 2、4、9 | 30 | `0x56` |
| 主动作 | 1 | 1、7 | 66 | `0x4B` |
| 主动作 | 1 | 0、6 | 62 | `0x43` |
| 主动作 | 1 | 2、3、8、9 | 44 | `0x45` |
| 主动作 | 1 | 2、9 | 52 | `0x54` |
| 主动作 | 1 | 2、9 | 108 | `0x55`，替代 GU 缺失的 4G request `0x57`／样本 |
| 主动作 | 1 | 2、9 | 109 | `0x4B` |
| 主动作 | 1 | 3、8 | 108 | `0x43` |

前置表除 `0x4C` 外，音效和特效都要求玩家 `+6` 的有瓶标志非零。主动作表不使用这个条件。起手 `0x48` 的主动播放仍注释。

原 MSS 屏蔽三项：`opcode=0x66 / bank=0`，第 62 帧 request `0x43`、第 112 帧 request `0x43`、第 24 帧 request `0x4A`。当前匹配的是当前玩家、命令和帧区间，代码没有再按 motion key 过滤；注释中的 `0x1412/0x1405/0x1413` 是这些规则的来源。

### 主动特效

| 所属函数 | actionState | variant | 创建帧 | 榴弹瓶／强属性瓶 ID | 持续帧 |
|---|---:|---|---:|---|---:|
| 前置 | 2 | 2、4 | 26 | `0x258 / 0x259` | 25 |
| 前置 | 2 | 0～15 中除 2、4 | 50 | `0x258 / 0x259` | 25 |
| 主动作 | 1 | 1、7 | 1 | `0x258 / 0x259` | 30 |
| 主动作 | 1 | 2、9 | 1 | `0x262 / 0x263` | 30 |
| 盾突 | 0（起手） | 六种 variant | 原初始化后 | `0x258 / 0x259` | 30 |

瓶型字段 `*(player+0x13C4)+0x356`，u16 的 0 为榴弹，非零为强属性。父对象使用 `player+0x23A4` 的盾牌对象、bone 0、UNIQUE 组 2、attachMode 0、局部位置与旋转均为 0。

持续时间累加粒子更新的 `+0x1C`，达到 25／30 后调用原停止函数 `0x0032A400(node,0)`；粒子仍可有原生淡出尾段。动作切换、命中和受击提前清除的旧逻辑保持注释。盾突仅在 `player+0x3344=2`（红盾）创建，未强化 0、黄盾 1、蓝盾 3 不创建；空挥也创建。盾突钩子为 `0x011DB280`，新增 request `0x47` 调用已撤除，主动粒子创建不提交 PTS 伴生音效。

### SRQ 与 PTS

SRQ 在 `0x00B67AE4` 绑定音库前修改。record 长度 `0x84`，以下偏移相对 record：

| request | 字段 | 原版 → 当前值 |
|---|---|---|
| `0x4A` | `+0x24 / +0x28` 两个 f32 音量 | `-3.9 / -3.9 → -1.9 / -1.9` |
| `0x4A` | `+0x34` u16 重播间隔 | `600 → 0` ms |
| `0x54` | `+0x02` cue 字段 | `0x7FFF → 0x7F4A`，实际 cue 低字节为 `0x4A` |
| `0x54` | `+0x08` 请求操作 | `2 → 1`，停止改为播放 |
| `0x54` | `+0x12` 分组第三项 | `10 → 200`；分组最终为 `0 / 2 / 200` |
| `0x54` | `+0x14` u8 优先级 | `0 → 110` |
| `0x54` | `+0x18` 声数上限 | `0 → 1` |
| `0x54` | `+0x24 / +0x28` 两个 f32 音量 | `0 / 0 → -2.4 / -2.4` |
| `0x54` | `+0x2C` 参数低 16 位 | `0 → 600`，保留整条 asset 快照值 |
| `0x54` | `+0x38 / +0x3C / +0x40` 三个 i32 | `-1 / -1 / -1 → 16 / 16 / 0` |
| `0x54` | `+0x54` 音库索引 | `-1 → 0` |

`0x54` 复制内置的完整 132 字节快照，以上为相对原版发生变化的字段。不要把 `+0x12` 当淡出时间、`+0x14` 当启播延迟：`+0x14/+0x15` 是两个 u8，当前为 `110/1`（优先级／替换方式）；真正启动延迟为 `+0x30`，当前 `0x4A` 和 `0x54` 均为 0。`0x4A` 的优先级 110、替换方式 1、声数上限 1 保持原版，只有音量和重播间隔由这段代码修改。

PTS 在 `0x004D923C` 原反序列化成功后修改 13 条记录，对象字段 `+0xC` request、`+0xE` 事件：

| 组 | effectId | 修改 |
|---|---|---|
| SEQUENCE | `0x226` | request `0x4A` 创建事件 1→0；request `0x56` 结束事件 3→0 |
| SEQUENCE | `0x258/0x259/0x262/0x263` | 创建 request `0x48→0x47` |
| UNIQUE | `0x1F4` | 结束 request `0x54→0`，事件仍为 3 |
| UNIQUE | `0x258/0x259/0x25D/0x25E/0x262/0x263` | 创建 request `0x48→0x47` |

两份文件可用原版，修改由 NRO 加载钩子完成；音效／特效逐帧日志关闭。音库样本等其它资源不在本 NRO 的替代范围。

## 2. Moveset：派生、盾补正及 J 防

| main 偏移 | 原值 → 当前值 | 用途 |
|---|---|---|
| `011DA634/011DA5EC/011DA610/011DA5C0/011DA43C` | `E3550002 → E3550005` | 黄盾分支比较 `2→5` |
| `011DA4B8/011DA4C0` | `00000040 → 000001A8` | 上黄盾派生改正常大解 |
| `011DF8B0` | `E3A01003 → E3A01002` | 红蓝盾补正档位改 2 |
| `011DF8D0` | `13A01001 → E3A01002` | 同上，使用无条件指令 |
| `0048859C` | `E3A0100F → E3A01014` | 大解瓶爆震动参数 `15→20` |

黄盾派生适用公会、空战、炼金；炼金只在 GP／蓄力斩之后正常大解，其它仍上黄盾。红／蓝盾补正 1.2，黄盾 1.0。

GP 在 `011DDE74` 跳进 NRO。装备 `+0x4D9` 为 1、3、5，或玩家动作字节 `+0x250A=0x54` 时执行 `r0|=0x20`；其它保留 r0。补回 `str r0,[r1]` 后返回 `011DDE7C`，实现用户原 GP 金手指的行为，不写 `013F1F58` 代码洞。

J 防桥接在 `002EA87C`，限定盾斧 14、风格 3、链 `0x81A`、序号 3；把这次栈命令改为 `act_st=0x10 / act_no=0x44 / act_param=0 / cmd_type=8 / cmd_param0=0x1B`，其余 cmd_param 为 0。保留 `Pre=20 / Start=30 / End=0`（10 帧起可预输入，30 帧开始执行），不替换共享 `071a` 资源。

## 3. SAED：第三下、瓶伤及瓶爆轨迹

### 直接补丁

| 用途 | main 偏移及当前值 |
|---|---|
| 地面第三下 | `011DADD4 E1A00004`；`011DADD8 E3A01000`；`011DADDC E3A02050`；`011DADE0 E3A03006`；`011DADE4 EBC37115`；`011DADE8 E320F000` |
| 地面后续帧常量 | `011DB18C 42DA0000`，`108.0→109.0` |
| 空中第三下 | `011DBDA0 E1A00004`；`011DBDA4 E3A01001`；`011DBDA8 E3A02023`；`011DBDAC E3A03006`；`011DBDB0 EBC36D22`；`011DBDB4 E320F000` |
| 空中后续帧常量 | `011DBE50 42DA0000`，`108.0→109.0` |
| 瓶伤 | `0048906C ED9F9A01`；`00489070 EEB71A00`；`00489074 EA000000`；`00489078 3FACCCCC`（固定系数 1.35） |
| 非零瓶数统一特效档位 | `011DE830 E3A09002`（r9=2，原版 4）；`011DE838 E3500000`；`011DE83C 1A000007` |

地面第三下读 HDP `0x50`，空中读 `0x23`，两个 BL 都调用原 `002B7240`。HDP 加载钩子 `00270C18` 在成功后将 80 条／4496 字节扩为 81 条／4552 字节，追加 56 字节的 `0x50`：`FramesBeforeHitbox=0 / FramesHitboxActive=8 / MotionValue=100`。不再修改 `011DB014`；原 `0x4F` 动作不再转用 `0x1A`。

固定特效档位不把实际瓶数改为 10，零瓶仍不创建瓶爆进程。档位直接修改 INI `[saed] effect_gear`（默认 2，允许 1..4），保存并重启；`enabled=false` 时整个 SAED 组关闭，包括这三处补丁。

### 计时、轨迹与贴地

瓶爆 init／update／destruct 钩子为 `00488C0C / 00488DE4 / 00488BDC`。参数对象 `shell+0x136C`：`+8` 的资源子类型 0～3 为榴弹，4～27 为强属性；`+0x11` 为剩余瓶数，支持 1～10，每次爆炸减 1。

榴弹首爆倒计时 **0**，强属性首爆倒计时 **46**，暂停 delta=0 时不触发。首爆当帧锁定人物坐标，朝向取 shell 初始化 yaw；下表时间相对实际首爆，距离相对锁定人物坐标，全部使用原 shell 的游戏计时单位。

| 爆炸序号 | 榴弹累计时间 | 榴弹前进／横向 | 强属性累计时间 | 强属性前进／横向 |
|---|---:|---|---:|---|
| 1 | 0 | 270 / 0 | 0 | 300 / 0 |
| 2 | 9 | 370 / 0 | 18 | 420 / 80 |
| 3 | 18 | 470 / 0 | 20 | 420 / -80 |
| 4 | 27 | 570 / 0 | 38 | 540 / -120 |
| 5 | 36 | 670 / 0 | 40 | 540 / 120 |
| 6 | 45 | 770 / 0 | 42 | 540 / 0 |
| 7 | 54 | 870 / 0 | 58 | 660 / -160 |
| 8 | 63 | 970 / 0 | 60 | 660 / 160 |
| 9 | 72 | 1070 / 0 | 62 | 660 / -160/3 |
| 10 | 81 | 1170 / 0 | 64 | 660 / 160/3 |

榴弹每爆前进 100、间隔 9。强属性前六点使用 4G 原表，七至十为 GU 十瓶增加的第四组。最后一爆之后再保留 9 个计时单位，再走原停止函数。每个有效更新最多爆一瓶。

每爆调用 GU 地面查询 `00181440`，探测区间依次为先前高度 `+300→-2000` 和 `+2000→+300`，未命中则保留先前 Y。世界位置写入 shell `+0x40/+0x44/+0x48` 和 `+0x1000` 镜像；特效与 hitbox 共用该坐标。复用原粒子和伤害函数；有特效创建时统一 `camera_shake(parent,20,1024)`。保留原参数 `+0x10` 禁止特效的条件。

SH 不读取来控制新序列，也不修改本地 SH；旧 `00488F5C/00488F74` 桥接及原代码洞均不再使用。

## 4. Hitdata：当前 asset，0x4F 原版

统一挂钩 HDP loader `00270C18`，原函数只调用一次。按开关扩容，复制 asset `0x00～0x4E` 的 79 条记录，写回内置 GU 原版完整 `0x4F`，设置独立新增 `0x50`。不再改 `01747CCC` 虚表；数据修改仅在成功加载时执行。当前生效的动作值差异如下：

| HDP ID | 原动作值 → 当前动作值 |
|---|---|
| `04/0C/0D/0F/1E/3F` | `42→47` |
| `05/40` | `33→40` |
| `14` | `45→60` |
| `15/1F` | `75→90` |
| `18` | `90→99` |
| `21` | `90→100` |
| `24` | `100→99` |
| `3A` | `70→95` |
| `43` | `35→60` |
| `44/4A` | `70→90` |
| `47` | `80→89` |
| `4D` | `80→99` |

`15/1F/21/44/4A` 的 **HunterArtFlag（record+0x0E）为 0→1**。这不是 `HunterArtGen`（`+0x26`），后者当前没有修改。除上述字段外，当前 `0x00～0x4E` 其余字节与原版一致。

`0x4F` 保持原版：`FramesBeforeHitbox=106 / FramesHitboxActive=6 / MotionValue=55`；不采用 asset 的 `0/8/100`。追加 `0x50` 由 `[saed] enabled` 控制，固定为 `0/8/100`。关闭 SAED 时不扩容，仍为 80 条。SAED 的 INI 只有 `enabled` 和 `effect_gear`。

## 5. Overpowered：超模后摇派生

保留原大解链 `0x7F4/0x7F5/0x839/0x83A`，原记录在前，追加当前风格 `0x7DC` 第 1 条起的后摇记录。红盾取消 `057a` 的窗口 `Pre=0 / Start=0 / End=28` 保留；正常斧竖劈自身的弹刀保持原版。

开启时只为超模安装 `002E9B7C` 派生初始化钩子，原函数先执行，再把当前盾斧玩家的表指针 `+0x24A8` 指向独立副本。链号、共享资源、原命令条件和窗口不改。五种风格追加 8 条，炼金追加 13 条；不再写入四处 `011DACF0/011DAF74/011DB0B4/011DB0FC`，也不再安装 `002EA864` 的弹刀屏蔽。默认关闭，详见 [Overpowered.md](Overpowered.md)。
