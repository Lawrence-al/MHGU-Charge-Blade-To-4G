# 武士道盾斧盾突派生 0x44

Moveset 新增 `[moveset] bushi_shield_thrust_aed`，默认 true：武士道盾斧盾突后 X+A 派生大解前置动作 `0x44`。Forge 菜单显示 **Adept shield thrust X+A routes to AED**，与原 `j_guard_aed` 独立启停，保存 INI 并重启应用。旧 INI 缺少此项时使用默认 true，菜单保存会补写。

## 证据、结论与实现

| 证据 | 具体发现 | 对应实现 |
|---|---|---|
| E-01：原版 `main.c` 中 `sub_611DB280`、`Make_AnimationWP_InitActionEfxMoveChain`；原 NSO 的 `main+0x0182CEC0` 与 `+0x016B10A0` | 盾突初始化参数的 `a2[4]` 指向链号 `0x7FA` | F-01：按玩家当前链号定位盾突；P-01：在现有 `main+0x002EA87C` 桥接中匹配 `player+0x24AC=0x7FA` |
| E-02：原武士道资源解析记录的表 42、第 1 条 | 原资源为 `plcmd_w14_0x0010_036a`，Pre=10、Start=34、End=0 | F-02：只替换本条临时命令；P-02：序号 `r8=1` 时写 action `0x44` 和 X+A 输入 `0x1B`，保留窗口 |
| E-03：asset 修改后的 `071a`，以及原 J 防桥接的命令字段 | 目标命令为 act_st=0x10、act_no=0x44、act_param=0、cmd_type=8；cmd_param0=0x1B，其余三个参数为 0 | F-03：可以复用同一段字段写入；P-03：不替换共享资源，也不修改盾突表第 7 条原 `071a` 命令 |
| E-04：实际新 NRO 的 ARM 执行与配置／菜单测试 | 四种开关组合、相邻链和序号、六风格／三武器、NZCV、整数／浮点寄存器、窗口和两个加载基址共 110,592 组通过 | F-04：两条派生可独立选择；P-04：启动写 `AED_ROUTE_FLAGS`，bit0=J 防、bit1=盾突，共用一处桥接 |

两条派生均限定装备武器字节 `+0x4D4=14`、风格字节 `+0x4D9=3`。J 防继续匹配链 `0x81A`、序号 3；两个开关均关闭时不安装该桥接。没有新增每帧 Rust 回调，也没有改 SAED、瓶伤、Hitdata 或其它风格的派生。

原输入位编号是 `0x1B`，不是动作 variant。窗口保留后，第 24 帧起可预输入，第 34 帧执行盾突后的新派生。覆盖的原指令补回后返回 `main+0x002EA884`。
