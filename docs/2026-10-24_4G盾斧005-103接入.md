## 持续时间

005两种瓶型的部分后续单元在第66个EFL tick才激活。103的前两组还含第21、26、36、41、66帧才激活的层。旧主动作30帧Stop会停止其后续生成，不能把Stop当成触发爆炸的指令。

原GU两条主动作继续使用原来的30帧，不再为4G覆盖这些数值。4G有独立配置：

```ini
[effects]
use_4g_sequences = false
aed_4g_duration = 0
saed_4g_duration = 0
```

`use_4g_sequences=true`开启4G。两项4G时长的0表示不登记额外停止计时，由EFL自然完成；正数可自定义停止发射时刻。前置两条保持各自任务的25帧，红盾盾突保持30帧，只播放前段。原任务Duration frames仍要求正数，仅独立4G本体时长允许0。

此前误接的独立gaxe_002命中和gaxe_104砸地功能已删除：模块、菜单、配置字段、钩子、诊断入口及旧专用资源包均移除。旧INI中的两键仅读取兼容并忽略，保存时不再输出。完整29项资源的逐个预览仍可选002/104，供识别原始资源使用，不会在实战中自动调用它们。
