# 4G盾斧转换特效复用审计

29项都需要整理调用参数，但不应统一重写29份EFL。完整转换包已经包含所需模型、材质、纹理和动画，可以供其它MHGU Forge作品使用；目前缺少的是按用途明确挂点、中心、分组和停止时机的通用调用层。现有005/103居中尾段应继续作为派生资源保留，不能覆盖完整序列。

## 范围和结果

检查 `assets/ported/cb_gaxe_preview_4g.arc` 的29份EFL、318个单元、29条PEL记录、转换脚本、现有调用接口；逐项读取4G原EFL并按转换时保存的SHA256确认身份。没有修改原ARC、转换包、4G dump、现有游戏逻辑或NRO；本次只增加审计脚本、目录和文档。

完整包560477字节，共45项：29 EFL、5 TEX、2 EAN、4 MOD、4 MRL、1 PEL。包内依赖闭合，PEL路径为 `effect\cb4gp\gaxe_preview`，使用UNIQUE组（kind=2）。原文件名编号001..018、050/051、100..108对应PEL的十进制ID1..18、50/51、100..108，不要把文件名107当成十六进制0x107。

## 如何保留资源

保留两类资源：

1. **完整版本**：当前29项ARC保持不变，用于原武器动作序列、逐项预览，以及需要原局部形状/时间线的作品。
2. **事件版本**：只针对语义已经确认的命中、落地等独立事件提取新资源。当前1005为005后段，1103为103砸下组；内部相对位置、曲线、层次和局部延迟继续保留。

005整组减Z200，103榴弹/属性分别整组减Z200/Z230，是从“武器坐标”转为“真实命中/砸下点”后的中心映射。这不能推广成其它资源都减200，或把每个controller的位置都清零。比如001的Z=-30/30/90/170是不同部位布局，107还有地表及爆炸层的不同高度。

005完整资源的后段延迟66；103原group2/3是在独立事件里另行创建的砸下组。保留完整005/103和新增尾段，才能同时支持需要动作序列和需要独立爆炸的作品。

尾包 `cb_gaxe_tails_4g.arc` 只有2 EFL+1 PEL，**不能单独拷走使用**：它引用完整包中的9项模型/材质/纹理/动画。加载次序是完整包、尾包；或者以后另打一个包含这些依赖的闭合事件包。

## 分组和地表如何选择

generator的第一个mask是单元组，第二个mask是地表，两者不能互相代替。原mask可以含多个bit表示共享层，不是每个数都代表一个互斥分类。直接全部设为0xFFFFFFFF会把不同瓶型、不同元素、普通/末瓶等层叠在一起。

| 已确认资源 | 调用约定 |
| --- | --- |
| 002 | 榴弹mask1、强属性mask2；继承真实附着对象；外部事件结束 |
| 003 / 008 | 一二解榴弹/属性单次瓶爆；008按实际元素位选择，使用原命中点 |
| 006 / 009 | 大解三次瓶爆每次单独创建；普通mask与末次mask区别保留，009末次元素mask左移10 |
| 1005 | 两瓶型mask1/2；命中继承部位参数，空挥继承原PSL砸下请求 |
| 1103 | 两瓶型mask1/2；砸下事件给固定世界位置和朝向 |
| 107 | group0普通榴弹、1末瓶榴弹、2..6元素、10..14末瓶元素；另外选地表mask |

其余资源的数值mask已完整记录，但没有据此杜撰它们对应哪个招式/瓶型。需要新增用途时，再结合原调用或游戏预览命名。

107的地面筛选通常为3，浅水为5；自动探测还可得到其它原生分类。贴地高度、地表筛选和场景颜色各自独立。现有107调用在实际爆点探测，避免读取旧父对象的水面缓存；通用新接口也应让调用者明确选择自动、指定地表或保持原记录。

## 后续作品如何调用

资源本身不要求加载当前Presentation的动作/音效功能。其它作品可以携带完整ARC并注册该PEL，按kind=2和对应ID创建。

现有 `gaxe.rs` 仍绑定 `STATE`、盾斧玩家和WeaponEffectShell；`link/exported.txt`只导出Forge回调。Rust的 `pub` 不表示另一个NRO可以直接调用它。后续应提取一个小型共用Rust模块/库，而不是要求其它NRO链接当前Presentation的内部函数。

共用模块的职责只需：

- 常驻ARC和注册PEL，返回稳定的资源句柄；尾资源先保证基础依赖在场。
- 提供“附加对象+bone+局部变换”与“固定世界点+朝向”两种创建方式。
- 显式接收资源ID、unit mask、surface mask/自动地表、贴地开关、缩放和停止策略。
- 返回可停止的node；区分停止发射与立即清已有粒子，析构时撤销句柄。
- 由调用者决定动作帧、命中、落地或首爆等触发事件，不把它们写进资源库。

先整理调用层就能消除当前预览PEL“全部默认贴地”的隐含条件。只在某资源确实需要独立事件版本时，再新增提取方案；不批量改原EFL，也不统一替换播放时间。
